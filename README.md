# Tareas de Sistemas Distribuidos

Este repositorio contiene las tareas y ejercicios realizados en Python para la materia **Sistemas Distribuidos**.

## Estructura

- Cada archivo Python corresponde a una tarea o ejercicio específico de la materia.
- Se recomienda usar un entorno virtual (`venv`) para instalar dependencias y evitar conflictos con otros proyectos.

## Requisitos

- Python 3.8 o superior
- [numpy](https://numpy.org/) (Para operaciones matemáticas y de álgebra lineal "rotacion.py")

Puedes instalar las dependencias ejecutando:

```bash
pip install numpy
```

## Ejemplo de uso

Para ejecutar el archivo de ejemplo de rotaciones (`rotacion.py`):

```bash
python rotacion.py
```

Esto imprimirá en consola el resultado de rotar un vector en el espacio usando matrices de rotación.

## Notas

- No subas la carpeta `.venv` ni archivos de entorno virtual al repositorio. Usa un archivo `.gitignore` para ignorarlos.
- Este repositorio está pensado para fines educativos y de práctica en la materia.
